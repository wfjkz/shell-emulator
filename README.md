# Эмулятор оболочки UNIX (вариант 16)

Консольный (CLI) эмулятор командной строки UNIX-подобной ОС на Python 3.

## Функции

- Приглашение формируется из реальных данных ОС: `username@hostname:~$`.
- Парсер делит ввод на команду и аргументы по пробелам.
- Команды:
  - `ls` — заглушка, выводит имя и аргументы;
  - `cd` — заглушка, выводит имя и аргументы (не больше одного);
  - `exit [код]` — завершает работу.
- Ошибки: неизвестная команда, неверные аргументы `cd` и `exit`.

## Параметры командной строки

| Параметр | Описание |
|---|---|
| `--vfs PATH` | путь к физическому расположению VFS |
| `--script FILE` | путь к стартовому скрипту |

При запуске выводятся все заданные параметры (блок `emulator config`).

## Стартовый скрипт

Команды эмулятора по одной в строке. Каждая команда печатается после
приглашения, затем её результат — как диалог с пользователем.
Скрипт останавливается на первой ошибке с сообщением
`error: script stopped at line N`, код завершения 1.
Примеры: `scripts/ok.txt`, `scripts/fail.txt`.

## Запуск и тесты

Нужен Python 3.8+.

```
run.bat [--vfs PATH] [--script FILE]
tests\test_repl.bat          этап 1: команды и ошибки
tests\test_all_params.bat    этап 2: все параметры
tests\test_with_script.bat   этап 2: стартовые скрипты
```

## Пример

```
semen@DESKTOP:~$ ls -l /home
ls: args=['-l', '/home']
semen@DESKTOP:~$ foo
error: foo: command not found
semen@DESKTOP:~$ exit
```
