# Эмулятор оболочки UNIX (вариант 16)

Консольный (CLI) эмулятор командной строки UNIX-подобной ОС на Python 3.

## Функции

- Приглашение формируется из реальных данных ОС: `username@hostname:~$`.
- Парсер делит ввод на команду и аргументы по пробелам.
- Команды:
  - `ls` — заглушка, выводит имя и аргументы;
  - `cd` — заглушка, выводит имя и аргументы (не больше одного);
  - `exit [код]` — завершает работу.
- Ошибки: неизвестная команда, неверные аргументы `cd` и `exit`.

## Запуск и тесты

Нужен Python 3.8+.

```
run.bat
tests\test_repl.bat
```

## Пример

```
semen@DESKTOP:~$ ls -l /home
ls: args=['-l', '/home']
semen@DESKTOP:~$ foo
error: foo: command not found
semen@DESKTOP:~$ exit
```
